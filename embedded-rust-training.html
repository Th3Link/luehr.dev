Four trainings, different goals

01

For developers getting started with Rust.

Rust Basics

Learn Rust from the ground up and apply it in a coherent program. Cover ownership, error handling, testing and cross-compilation.

Ownership · Traits · Testing · Cross-compilation

3–4 days · from €12,000 plus VAT

Remote or on-site · 5–10 participants

02

For teams building applications on Linux devices.

Rust Advanced: Embedded Linux

Rust for applications and services on Embedded Linux. Concurrency, D-Bus and web APIs, with testing and a secured build and release pipeline.

Async Rust · D-Bus · axum · CI/CD

3–4 days · from €12,000 plus VAT

Remote or on-site · 5–10 participants

03

For teams developing microcontroller firmware.

Rust Advanced: Embedded no_std

Rust directly on the microcontroller, without the standard library. Work with Embassy, embedded traits, constrained memory and hardware debugging.

Embassy · embedded-hal · heapless · SWD/JTAG

4 days on-site · €15,000 plus VAT

Remote only in exceptional cases.

For technical leaders evaluating Rust adoption.

Rust for Engineering Managers

A practical introduction to the opportunities, costs and trade-offs of adopting Rust. Evaluate technical constraints and realistic migration strategies.

Rust vs. C/C++ · Adoption · Migration · Decision criteria
