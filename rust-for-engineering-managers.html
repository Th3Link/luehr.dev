Who is it for?

Engineering managers, CTOs, technical directors, software and firmware team leads, technical project managers and architects responsible for technology decisions.

Prior knowledge

Technical interest and responsibility for technology decisions. This workshop is an accessible introduction, rather than a programming course.

What we cover

Why Rust?

The problems Rust addresses in memory safety, concurrency and software reliability.

Rust vs. C/C++

Technical differences, constraints and their impact on existing embedded projects.

Business value

Reducing specific classes of bugs, improving maintainability and assessing long-term software quality.

Adoption challenges

Learning curve, productivity, recruiting, tooling, libraries and integration with existing codebases.

Migration strategies

Pilot projects, incremental adoption, C/C++ interoperability and realistic starting points.

Making the decision

Criteria for when Rust makes sense and when the effort outweighs the benefit.

How we work

We look at Rust from a practical embedded engineering perspective. Technical concepts are explained without going unnecessarily deep into syntax or implementation details. The goal is an informed decision, including when Rust is not worth adopting.
