Engineering Beyond Work

I've relied on open source software throughout my entire career and strongly prefer open technologies whenever practical. Over the years I've built up a growing collection of personal projects, ranging from Rust networking libraries to complete hardware and software systems. These projects allow me to explore new ideas, validate approaches and stay connected to hands-on engineering.

IPv6 Router Advertisement Crate

A Rust implementation for IPv6 Router Advertisement handling, developed with a focus on code quality, testing, maintainability and embedded use cases.

Open Home Automation Platform

An home automation platform combining custom hardware, embedded software and system integration. Developed and operated in real-world environments, the project demonstrates scalable embedded design, long-term maintainability and cost-efficient deployment.
